# SMILES to 3D Docking with Gold

This repository follows the virtual workshop which takes you through building a workflow to dock multiple ligands from their starting SMILES strings. 
The CSD conformer generator is used to generate 3D conformers; the ligand overlay tool is used to overlay them; and GOLD is used to dock them to the same protein.

The accompanying worksheet can be found [here](https://www.ccdc.cam.ac.uk/Community/educational-resources/virtual-workshops/smiles-to-3d-docking-with-gold/).

---
## Requirements

- [GOLD](https://www.ccdc.cam.ac.uk/solutions/csd-discovery/components/gold/), CSD Conformer Generator, CSD Data and the [CSD Python API](https://downloads.ccdc.cam.ac.uk/documentation/API/) installed.
  
## Licensing Requirements 

CSD-Discovery, CSD-Enterprise

## Instructions on Running

To run the scripts, an environment with the CCDC Python API installed must be active. Then simply run the script from the command line or your favoured IDE.
