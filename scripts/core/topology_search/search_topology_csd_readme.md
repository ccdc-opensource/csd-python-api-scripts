# Topology search

## Summary

Extract structure identifiers from the CSD by topology identifiers

## Available data

This search acts on any .sqlite file that is in the CSD Data folder
(generally %USER%/CCDC/ccdc-data/csd) that includes topology information
(the "TOPOLOGY_PROPERTIES" table).
This is available from the 2026.3 release ("./as602be_CIP.sqlite")

2026.3:

- MOF subset & related compounds (162933 structures)

## Searchable fields

The calculations performed for topology determination are based on the CCDC
 topology assignment tool, written for the CSD-Python-API (Sykes, Richard A.,
 Natalie T. Johnson, Christopher J. Kingsbury, et al. “What Has Scripting Ever
 Done for Us? The CSD Python Application Programming Interface (API).” Journal
 of Applied Crystallography 57, no. 4 (2024): 4. <https://doi.org/10.1107/S1600576724005934>.).
 The calculations follow a network assignment technique outlined in Öhrström, Lars, and
 Krister Larsson. Molecule-Based Materials: The Structural Network Approach. 1st ed.
 Elsevier, 2005.

MOF topology is determined by "Single Nodes"-like definition (Charlotte Bonneau,
 Michael O’Keeffe, Davide M. Proserpio, et al. “Deconstruction of Crystalline
 Networks into Underlying Nets: Relevance for Terminology Guidelines and
 Crystallographic Databases.” Crystal Growth & Design 18, no. 6 (2018): 3411–18.
 <https://doi.org/10.1021/acs.cgd.8b00126>.). Each contiguous ligand, metal ion,
 metal cluster or metal-oxo cluster is represented as a point in space, and the
 topology is determined after generating a simplified version of the network
 (a graph minor) that removes isolated (connectivity=0) and terminal (c=1) nodes,
 and bypasses bridging (c=2) nodes.

This network is represented by the string information in the calculated fields.

More information can be generated by using the topology tool in CSD-Python-API ->
 Prototypes -> Topology -> Topology Menu and inspecting the documentation.

## Topology vertex symbol

A vertex symbol is a representation of the local connectivity of a representative
 node of the unbounded network. The vertex symbols here are of the form:
 `A(B<sub>C</sub><sup>D</sup>.B<sub>C</sub><sup>D</sup>…)<sup>E</sup>` + ...
 where a node of connectivity A is connected to itself by cycles of length B,
 degeneracy C and multiplicity D, with E equivalent nodes in the repeating unit.
 There are a few differences from those vertex symbols generally available in the
 literature to retain compatibility across 2D and 3D types of networks and to
 provide more specificity and information.

1. Redundant cycles are not replaced by “*”;
2. Cycles are ordered from smallest to largest;
3. 2-connecting pseudo-nodes are included by default;
4. Degeneracy of individual cycles are tracked
5. Non-closing cycles (&ge;32) are given the name “∞”

For example, the " Double-layer square grid (eclipsed)" structure of hydrogen
 bonding in GLYCIN28 consists of two square grid motifs that are connected into
 a bilayer at every vertex. This 2D network has a vertex symbol:
 `5(4<sup>8</sup>.8<sub>10</sub><sup>2</sup>)`
 meaning this is constructed of 8 4-loops and 2 10-fold-degenerate 8-loops.
 This may also be represented as 4.4.4.4.4.4.4.4.\*.\*

## Topology dimensionality

Dimensionality is the total number of orthogonal directions traversed by connected
 elements of a topological network. This is assigned by traversal of the network of
 connected nodes to 24 links and taking the coordinates of crystallographic unit
 cell translation that apply to each node. In unit cell integer coordinates, the
 normal to plane containing these nodes is fitted (where appropriate) as "z", and
 the unit cross product of this and the most distant point is assigned as "y".
 The cross product "y" \cross "z" is assigned "x".

Dimensionality is assigned by mean of all points in these orthogonal directions
 being below the threshold value of 0.1. i.e. mean(v(x)) > 0.1 is 1D,
 mean(v(x)) > 0.1 & mean(v(y)) > 0.1 is 2D,
 and mean(v(x)) > 0.1 & mean(v(y)) > 0.1 & mean(v(z)) > 0.1 is 3D.

For example, the network of connected elements in ABIXAL is bridged by Cl- ligands
 to equivalent elements in the `[-1 0 0]` and `[1 0 0]` unit cells and by 4,4'-bipyridine
 ligands to the `[1 1 0]` and `[-1 -1 0]` unit cells. As such the population of connected
 unit cells involves all in the *ab-* plane. Mean v(z) value is exactly 0.0, whereas
 mean(v(x)) = 34.70 and mean(v(y)) = 29.73 (i.e. >> 0.1)

## Topology RCSR assignment

The Reticular Chemistry Structural Resource (RCSR) is the preferred method of
 referring to topology where applicable. An assignment in this database is a
 three-letter code that identifies common 2D or 3D network topologies. For
 example "dia" refers to the diamondoid three-dimensional topology, and
 "sql" refers to the common square lattice.

Assignment to an RCSR code is using a predetermined lookup table that assigns
 these RCSR codes to vertex symbols and CS10 values, as indicated
 below for the unique identifier.

## Topology CSD unique identifier

The CSD unique identifier is a short identifier that contains information on
 the vertex symbol and dimensionality, reduced to an easy-to-search
 code. An example is "layers/giyrffmn" that represents the
 "Double-layer square grid (eclipsed)" structure that has no RCSR identifier.
 The prefix "zero" or "rods" or "layers" or "nets" indicates 0, 1, 2 or
 3-dimensional structure respectively. The second part of the identifier
 is based on the sha1 hash of the (printable) vertex representation and cs10 value.
 This is the number represented by the hash in base 26, transliterated to a
 series of lowercase letters. As such, the identifier is the same for structures
 with the same vertices.

For example, the string "5(4^8.8(10)^2):402" represents the vertex and cs10 values
 for this net, rendered through the hash_str function to "giyrffmn". More information
 is available through the program reference and source.

## Outputs

A short report gives a summary of the query as performed. The input parameters,
 the SQL query, the total number of hits / structures that are identified and
 the number of those that are displayed (first 1000 by default)

The structures are delivered as a ".gcd" list of structures and a ".tsv" that
 contains topology information from the sqlite database. This contains the
 searchable fields above.

A visualisation of any given structure can be obtained by reanalysis of the
 topology of that structure using the tool at CSD-Python-API -> Prototypes ->
 Topology -> Topology Menu
